# G13 imagegen prompt set

Built-in imagegen, transparent_background=true; one generation per Pet.
Each Pet uses `r2-upload/sprite/pet/<folder>/animations/<id>_idle_0.png` as the sole identity reference; Sprout folder is `sprout001`, others equal ID.

## sprout

Create exactly one ThornieDungeons G13 sprout production avatar. Input is the approved character identity reference; preserve its exact species, face, colors, markings, horns/ears/leaves, and painted chibi game art style. Recompose a clear head and upper torso portrait only, centered, slight three-quarter view matching reference. No redesign, no new accessories. Keep all ears/horns/leaves within the square, strong readable silhouette at 32px, consistent family portrait composition, at least 8% transparent safe padding on every side. Transparent background, no frame, no words, no glow field, no UI. Output square PNG, target 256x256 production canvas if possible. This is a new portrait derived from the supplied approved reference, not a full-body sprite.
